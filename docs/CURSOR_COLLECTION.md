All start at visual size 40 on a fresh install (logical points on Mac, device-independent
units on Windows). System Default restores the OS cursor scheme and follows
system size and color settings.

curated names once without duplicates; existing sizes, click points, and favorites
remain intact. Subsequent edits and deletions are preserved. Imported packs retain
their authored sizes.
